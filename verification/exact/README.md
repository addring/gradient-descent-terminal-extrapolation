# 固定步长末端外推：本次复核材料

日期：2026-10-10。

本包随《固定步长末端外推：渐近定理完整证明》逐式复核与整理版提供。此目录提供精确核验程序及结果快照。

## 内容

| 文件 | 内容 |
|---|---|
| run_exact_checks.py | 标准库一键入口，重新运行全部有限精确检查 |
| exact_summary.json | 一键入口的实际运行汇总 |
| check_asymptotic.py | 能量、平移、可行方向、修正界及扰动界的精确检查；另含可选数值诊断函数 |
| check_asymptotic_results.json | 本次能量精确检查和大 N 浮点诊断的完整输出 |

| results.json | 7 组反例、1,256 条有向约束的输出 |

## 一键精确复现

解压后，在本目录打开终端，运行：

```
python run_exact_checks.py
```

该入口只需 Python 3 标准库。它不会安装软件、读取旧项目资料或访问网络。
输出汇总保存为 exact_summary.json；证书和反例的输出文件会在同一目录重新生成。

全部通过/失败判断使用 fractions.Fraction 的精确等式与符号。证书样例的活动集仅作为候选输入；程序从原目标重新恢复矩阵、精确求解 KKT，并核对全部原始约束、乘子符号、互补性和驻点方程。

程序还显式检查原稿的两个错误公式确实在正文给出的有理数例子上失效。

## 可选的大 N 数值诊断

check_asymptotic_results.json 已含本次实际运行的诊断数据，无需重新运行即可查看。
如希望重新生成，需在有 NumPy 的环境中运行：

```
python check_asymptotic.py
```

这一可选命令覆盖 N=100、1,000、10,000、100,000、1,000,000 及 t=1、2、20。
浮点结果仅用于观察有限规模行为；不用于判断精确正性，也不承担渐近证明。
